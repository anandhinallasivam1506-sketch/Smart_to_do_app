In fast-paced academic and professional environments, individuals face an overwhelming volume of daily tasks, assignments, and deadlines. Traditional tracking methods—such as physical notebooks, basic text documents, or simple digital checklists—suffer from 
a critical flaw: they treat all tasks equally.
When using a standard checklist, items are displayed chronologically in the exact order they were typed. As the list grows longer, a user must manually review the entire list repeatedly to determine what to do next. This causes three major issues:
        Cognitive Fatigue: Wasting time and mental energy trying to manually sort, filter, and figure out what to work on next.
        Missed Deadlines: Urgent, high-priority tasks get buried under minor, unimportant daily tasks and are completely forgotten.
        Inefficient Workflows: Users naturally pick and check off the easiest tasks first to feel productive, leaving critical, high-impact tasks neglected
The Solution
This project eliminates this cognitive friction by automating task organization. By implementing a programmatic sorting engine using Python and Streamlit, the application instantly establishes a visual hierarchy. It takes over the organizational load, turning
a chaotic, unorganized list into an optimized, actionable daily roadmap.
